# Ledger

Personal money app: net worth, monthly budget with a daily spend number, debt payoff plan, goals, and a future-you projector.

Install on iPhone: open the GitHub Pages address in Safari → Share → Add to Home Screen.

- Data is saved on the device only; nothing personal is stored in this repository.
- `src/freedom-ledger.html` is the shared app source. Rebuild with `python3 tools/build.py src/freedom-ledger.html .`
